# Phase 2: Reproducible Synthetic Historical Dataset Generator

## Purpose

This generator creates a small synthetic historical dataset for ML experimentation and evaluation without modifying the Phase 1 runtime or database schema.

It reflects the approved design in 6.2.1 and is intended for:

- model evaluation
- comparison with the Phase 1 rule engine
- dataset validation and reproducibility checks
- offline experimentation only

## Entry point

From the backend folder:

```bash
node src/intelligence/generate-recovery-dataset.js --seed 42 --row-count 6000
```

## Output

The script writes to:

```text
data/phase-2/
```

Generated files:

- `recovery_dataset_v1.csv`
- `recovery_dataset_v1.metadata.json`

## Reproducibility

Use a fixed seed to reproduce the same dataset.

```bash
node src/intelligence/generate-recovery-dataset.js --seed 42 --row-count 6000
```

## Changing the dataset size

```bash
node src/intelligence/generate-recovery-dataset.js --seed 42 --row-count 8000
```

## Validation

The generator validates the dataset before writing it. Validation checks include:

- required fields present
- valid categorical values
- positive transaction amounts
- valid timestamps
- non-negative failure counters
- duplicate candidate-action rows prevented
- action coverage present
- target distribution not degenerate

## Reproducing a previous dataset

Use the same seed and row count:

```bash
node src/intelligence/generate-recovery-dataset.js --seed 42 --row-count 6000
```

The generated metadata file records the seed and configuration so the prior run can be reproduced exactly.
The generated metadata file also records the exact CSV SHA-256 checksum. A separate run-summary file is not created because the canonical metadata contains the reproducibility information.
