# Recoverly Frontend

React and Vite frontend foundation for the Payment Failure Recovery API.

## Setup

1. Copy `.env.example` to `.env` and adjust `VITE_API_BASE_URL` if needed.
2. Run `npm install`.
3. Run `npm run dev`.

## Commands

- `npm run dev` - start the Vite development server.
- `npm run build` - create a production build.
- `npm run lint` - run ESLint.

The current phase provides the application shell and dashboard foundation only. Transaction, payment attempt, and recovery workflows are intentionally not implemented yet.
